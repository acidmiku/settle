Settle 0.2.3 fixes database upgrades from older builds and keeps WYSIWYG heading formatting scoped to the selected lines.

### Fixed

- **“sqlite error: no such table: folders”** when creating or listing folders. Older builds had already used migration numbers 2 and 3 for unrelated changes, causing 0.2.2 to skip the new library schema.
- Startup now repairs the missing library table and fields automatically. It preserves note text, existing names and folders, drafts, settings still used by the editor, archived content, and the original migration history. No database reset is needed.
- Editor migrations now have separate named records to avoid those historical number collisions. The repair runs in one transaction and can be retried safely if it fails.
- **Heading formatting in WYSIWYG** now affects only the selected lines, or the current line when there is no selection. Single Markdown line breaks no longer cause the whole paragraph to become a heading. Surrounding text and inline formatting are preserved, and the change can be undone in one step.
- The formatting toolbar preserves the text selection when its heading dropdown takes focus.

### Updating

Open **Settings → Check for updates → Install update**, or download the Windows x64 installer or universal macOS DMG below.

macOS builds support Apple Silicon and Intel on macOS 12.3+, remain ad-hoc signed, and are not notarized. The `.sig`, `.app.tar.gz`, and `latest.json` assets are used by the updater.
