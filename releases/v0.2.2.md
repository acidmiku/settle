Settle 0.2.2 adds folders, note names, and visual Markdown editing. Saving now keeps the current note open so you can keep writing.

### What's new

- **A continuous notes list**, grouped under date labels, replaces the date dropdown. Browse all notes, unfiled notes, or a folder, and load older notes as needed.
- **Rename notes** by double-clicking their label or using the right-click menu. Names are separate from the note's text and appear in search results and exports.
- **Folders** let you organize notes and move them between folders. Rename or delete a folder from its menu; deleting a folder keeps its notes in Unfiled.
- **Individual tab close buttons** offer Save and close, Discard, or Cancel when a note has unsaved changes. A failed save leaves the tab open.
- **A saved-status dot** in the editor footer shows green for saved content and red for unsaved changes or a new draft.
- **WYSIWYG Markdown editing** appears beside the language selector when Markdown is selected or detected. Edit rendered text with controls below the tabs for headings, emphasis, lists, checklists, quotes, links, code, tables, rules, and undo/redo. Each tab remembers its view.

### Fixes and data handling

- **Ctrl+S / Cmd+S saves in place**, preserving the open tab, content, selection, and editing view. Repeated saves update the same note instead of creating duplicates. The Save button follows the same behavior.
- Existing notes migrate automatically and start in Unfiled. Folder and note names are included in JSON and Markdown exports; search also matches note names.
- Switching between Markdown source and visual editing without edits preserves the source exactly. Visual edits may normalize Markdown formatting. Notes containing raw HTML stay in source mode to preserve their markup; images appear as labels without fetching remote files.

### Installing this release

From 0.2.1, open **Settings → Check for updates → Install update**. Users on 0.2.0 need to install this release manually once to gain the updater.

- **Windows:** download the x64 setup executable.
- **macOS:** download the universal DMG for Apple Silicon and Intel (macOS 12.3+), then copy Settle into Applications. macOS builds remain ad-hoc signed and are not notarized.

The `.sig`, `.app.tar.gz`, and `latest.json` assets are used by the updater.
