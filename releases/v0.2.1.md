Settle 0.2.1 adds word wrap, in-app updates, and optional startup at login.

### What's new

- **Word wrap** in Settings → Writing, enabled by default for every design and syntax. Turn it off for horizontal scrolling. The preference is shared across tabs and survives restart.
- **Check for updates** in Settings shows the installed version and checks the latest stable release. An **Install update** button appears when a newer version is available, with download progress and release notes.
- **Start with OS** in Settings opens Settle when you sign in on Windows or macOS. It defaults to off and reflects the actual OS registration.
- Opening Settle again brings the existing window forward instead of creating another instance.

### Reliability

- Updates are downloaded over HTTPS and verified against Settle's signing key before installation. Drafts must finish saving before an update can proceed. Download or installation failures keep the editor available for retry.
- Wrapping preserves the original text, caret selection, syntax highlighting, and logical line numbers across all ten designs.

### Installing this release

Users on 0.2.0 need to install 0.2.1 manually once; 0.2.1 introduces the updater for future releases.

- **Windows:** download the x64 setup executable.
- **macOS:** download the universal DMG for Apple Silicon and Intel (macOS 12.3+), then copy Settle into Applications before enabling startup or installing future updates. macOS builds remain ad-hoc signed and are not notarized.

The `.sig`, `.app.tar.gz`, and `latest.json` assets are used by the updater.
