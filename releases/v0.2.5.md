Settle 0.2.5 makes the Tab key indent in the editor and adds indentation controls to the footer.

### Added

- **Tab indents instead of leaving the editor.** `Tab` indents and `Shift+Tab` outdents in the source editor. With several lines selected, both act on every selected line, and native Undo reverses each step. ([#2](https://github.com/acidmiku/settle/issues/2))
- **Indentation menu at the right of the footer.** Choose a tab size of 2, 4, or 8 and turn on **Indent using spaces** to insert spaces instead of tab characters. The tab size also applies to tabs in Markdown preview and WYSIWYG code blocks.
- **Show tabs and spaces.** The same menu can mark each tab with an arrow and each space with a dot in the source editor, in plain text and highlighted code. Your text is unchanged.
- Indentation choices apply to every tab and survive restart.

### Updating

Open **Settings → Check for updates → Install update**, or download the Windows x64 installer or universal macOS DMG below.

macOS builds support Apple Silicon and Intel on macOS 12.3+, remain ad-hoc signed, and are not notarized. The `.sig`, `.app.tar.gz`, and `latest.json` assets are used by the updater.
