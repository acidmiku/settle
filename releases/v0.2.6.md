Settle 0.2.6 adds a character count to the footer.

### Added

- **Character count.** The footer shows how many characters the current note has, next to the caret position.
- **Selection size while selecting.** Select text and the count changes to the selection, such as `3 lines, 46 characters selected`. It updates as you drag or extend the selection with the keyboard, and returns to the total when the selection collapses.
- **WYSIWYG counts.** In WYSIWYG mode the footer shows words and characters of the visible text, and the selected characters while selecting.
- Emoji count as one character, and line breaks are included, as in Sublime Text.

### Updating

Open **Settings → Check for updates → Install update**, or download the Windows x64 installer or universal macOS DMG below.

macOS builds support Apple Silicon and Intel on macOS 12.3+, remain ad-hoc signed, and are not notarized. The `.sig`, `.app.tar.gz`, and `latest.json` assets are used by the updater.
