Settle 0.2.4 fixes syntax highlighting flicker while typing on Windows and macOS.

### Fixed

- **Syntax colors no longer disappear on every keystroke.** Highlighting updates immediately in the current language while automatic language detection still waits for a pause in typing. This applies to both manually selected languages and Auto mode. ([#1](https://github.com/acidmiku/settle/issues/1))
- Regression coverage checks that colors and text stay in sync during typing, deletion, text replacement, undo, and composition input in Chromium and WebKit.

### Updating

Open **Settings → Check for updates → Install update**, or download the Windows x64 installer or universal macOS DMG below.

macOS builds support Apple Silicon and Intel on macOS 12.3+, remain ad-hoc signed, and are not notarized. The `.sig`, `.app.tar.gz`, and `latest.json` assets are used by the updater.
